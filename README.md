Native Android App using Kotlin within Android Studio to help users study and verify hacks with questions. The app displays questions, loops through each hack whether True/False or Hacks and Urban Myths. The layout is built using XML and follows a clean, design to enhance user experience and readability.
Application built using Kotlin in Android Studio which helps the user’s study and maintain focus with interactive buttons and use of the Toast features within Kotlin
